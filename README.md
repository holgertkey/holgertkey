# Hi, I'm Holgert

**Rust developer building fast, focused tools for people who live in the terminal.**

I like small programs that do one job well: a single binary, no runtime, instant startup,
and a keyboard-first interface. Most of what I publish is cross-platform (Linux and Windows)
and grew out of friction in my own daily workflow.

---

## 🛠 Featured projects

### Rust

| Project | What it does |
|---|---|
| [**tagent**](https://github.com/holgertkey/tagent) | Translate selected text anywhere with a hotkey. Terminal app, Slint desktop app with tray and popup, and a reusable library. Google, DeepL or any OpenAI-compatible LLM (Ollama, LM Studio); dictionary and text-to-speech. Windows and Linux (X11, Wayland). |
| [**ccalc**](https://github.com/holgertkey/ccalc) | A terminal calculator with Octave/MATLAB syntax and script support — one binary, no runtime. [Docs](https://holgertkey.github.io/ccalc/) · [scripts](https://github.com/holgertkey/ccalc-scripts) |
| [**bmrk**](https://github.com/holgertkey/bmrk) | Inline TUI for jumping between directories and managing bookmarks, with fuzzy search and quick-jump. Available on [crates.io](https://crates.io/crates/bmrk). |
| [**dtree**](https://github.com/holgertkey/dtree) | Interactive directory tree navigator with a built-in file viewer — `tree` meets a modern file manager. |
| [**ccaps**](https://github.com/holgertkey/ccaps) | Lightweight Windows utility that repurposes Caps Lock for instant keyboard layout switching. |

### Yazi plugins (Lua)

| Plugin | What it does |
|---|---|
| [**pin-folder.yazi**](https://github.com/holgertkey/pin-folder.yazi) | Pins a directory into the Parent column as a fully interactive, independently navigable view. |
| [**command-line.yazi**](https://github.com/holgertkey/command-line.yazi) | An always-visible shell prompt inside Yazi: auto-quoted tokens, captured output with a live log preview, and a cwd that stays in sync. |
| [**bookmarks.yazi**](https://github.com/holgertkey/bookmarks.yazi) | Ten directory bookmarks on the digit keys, managed from one which-key panel and persisted across restarts. |

## 🎯 What I care about

- **Speed and small footprint** — tools should start instantly and stay out of the way.
- **Keyboard-first UX** — every action reachable without a mouse.
- **Good documentation** — every project ships with a clear README, changelog and help.
- **Open source** — I publish my tools under the MIT license and welcome issues and PRs.
